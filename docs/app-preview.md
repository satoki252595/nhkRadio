# Playback for Notion — App Store App Preview（日本語）

App Storeの製品ページに載せるApp Preview（iPhone縦）の制作手順・判断・撮影リスト。
審査用の動作確認動画（App Review向け）とは別物で、互いの証跡に流用しない。

## 現状（2026-10-25）

- **公開版は candidate9 の final-v2。** TestFlight 1.0.0 (8)（source `7c90e6e2275c`）を実機iPhone 16e（iOS 27.0.1）で収録した映像だけを使い、自動チェックはすべて通過した（状態は `PASS_PENDING_HUMAN_REVIEW`）。出力は `~/.config/playback/release/candidate9/app-preview/final-v2/`。構成と判断は下の「公開版（candidate9、ビルド8）」を参照。アップロード・審査提出は親が行う。
- 最初の書き出し（v1、`app-preview/` 直下）は、最後の字幕を直す前の版として監査用に残している。アップロードには使わない。
- 以前のDRAFT（ビルド3の映像）は記録として残すが、使わない。
- 出力物・QA・EDL・レポートはGit外の非公開リリース証跡ディレクトリ（`~/.config/playback/release/candidate9/app-preview/`）に置く。このrepoには入れない。

## Appleの仕様（2026-10-22に公式ページで確認）

出典: [App preview specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/app-preview-specifications/)、[Show more with app previews](https://developer.apple.com/app-store/app-previews/)

| 項目 | 値 |
|---|---|
| iPhone縦（Dynamic Island／Face IDの大・中画面とも） | 886×1920 |
| 長さ | 15〜30秒 |
| 映像 | H.264 High Profile Level 4.0以下、プログレッシブ、最大30fps、目標10〜12 Mbps（ProRes 422 HQも可） |
| 音声 | ステレオ、AAC 256 kbps、44.1/48 kHz、全トラック有効 |
| 形式・容量 | .mov/.m4v/.mp4、最大500 MB |
| ポスターフレーム | 既定は5秒。承認後に変えると新しいプレビューの提出が必要 |
| 枚数 | 端末サイズ・言語ごとに最大3本 |

内容のルール（Appleのガイドラインより）: アプリ内で撮った映像だけを使う。端末を操作する手や肩越しの撮影は不可。場面の切り替えで、アプリに無い機能を匂わせない（ディゾルブやフェードを推奨）。表示する権利のある素材だけを使う。ログインが必要なアプリは映像内か最後のフレームで明示する。日付や季節の言及、具体的な価格は入れない。既定では無音で再生されるため、字幕は読める大きさで十分な時間出す。

このプロジェクトで追加しているルール: 端末フレームを付けない。作ったUIや合成したボタンを使わない。IAPや未出荷の機能を見せない。NHKなど第三者の放送の映像・音声を使わない。設定画面（ビルド番号・ソースハッシュ）とNotionのOAuth画面は映さない。音声トラックは生成した無音にする。

## 書き出し

依存はすべて `nix develop` のFFmpeg/ffprobe/Python（標準ライブラリのみ）を使う。字幕フォントはmacOS標準のヒラギノ角ゴシック W6（`--font` か `APP_PREVIEW_FONT` で変更できる）。音声はmacOSのAudioToolbox AAC（`aac_at`、CBR 256 kbps）でエンコードする。FFmpeg内蔵のAACエンコーダーでは、無音が約2 kbpsまで落ちてAppleの指定を満たさないため。

```sh
nix develop --command python3 -I scripts/render_app_preview.py sheet \
  --input "$SRC" --out "$OUT/inspect.jpg" --start 20 --duration 60 --crop 16:76:494:1048

nix develop --command python3 -I scripts/render_app_preview.py render \
  --edl "$OUT/edl/<name>.json" --input "$SRC" --output-dir "$OUT"
# QAだけやり直す場合: render を qa に置き換える
```

`render` を実行すると、次のものが `$OUT` に出力される。

- `<name>[-DRAFT].mp4`: 886×1920、30fps CFR、H.264 High@4.0、約11 Mbps CBR、AAC 256k 48 kHzステレオ（無音）、faststart、メタデータ除去
- `<name>[-DRAFT]-poster.png`: `poster_seconds` の位置のフレーム
- `<name>[-DRAFT]-report.json` / `.md`: 仕様チェック、来歴、各ファイルのSHA-256、ツールのNix storeパス・バージョン・ハッシュ
- `qa/<name>/`: ffprobeの結果、全デコードのログ、フレームごとのmd5による時系列と1秒ごとのハッシュ、0.5秒間隔のコンタクトシート、全カット境界の元フレーム（in、in+0.1、out−0.1、out−1f）、ディゾルブの前・中・後、black/freeze/volumeの検出結果

EDLの `footage` が `target` と同じversion/buildで、かつ `verified_on_device: true` でない限り、自動的にDRAFTになる。その場合レポートの状態は `DRAFT_NOT_FOR_UPLOAD` になる。

### EDLの例（パスはCLIで渡すので、EDLには絶対パスを書かない）

```json
{
  "name": "playback-app-preview-ja-886x1920",
  "target":  {"version": "1.0.0", "build": "6", "locale": "ja"},
  "footage": {"file": "<raw capture>", "version": "1.0.0", "build": "6", "verified_on_device": true},
  "size": [886, 1920], "fps": 30, "video_bitrate": "11M", "audio": "silent",
  "crop": {"x": 0, "y": 0, "w": 1170, "h": 2532},
  "transition_seconds": 0.4, "fade_out_seconds": 0.5, "poster_seconds": 5.0,
  "caption_style": {"fontsize": 38, "boxcolor": "0x3A3A3C@0.94", "boxborderw": 18},
  "segments": [
    {"id": "library", "in": 3.0, "out": 6.6,
     "captions": [{"text": "Notionのデータベースをライブラリに", "y": 0.55}]}
  ]
}
```

`crop` は録画のうちiPhone画面部分だけを切り出す範囲。Mirroringのツールバー、ウィンドウの縁、ステータスバーは含めない。`captions[].y` は画面の高さに対する割合で、ネイティブUIの空いている場所に置く。

任意の項目:

- `corner_radius`（出力のpx）: 画面の角丸の外側に見えるMirroringウィンドウの地色を、黒い角丸マスクで隠す。UIを削らずに済む。0か省略でマスクなし。
- `captions[]` の `size`・`fontcolor`・`boxcolor`・`boxborderw`: 字幕ごとに `caption_style` を上書きする（クレジットを小さく控えめに出す場合など）。

## DRAFT（ビルド3の映像）の構成と、ビルド6との差分確認

元映像はビルド3をMirroringで録画したもの（526×1140、可変フレームレートで約29.2fps）。そこから画面部分 484×1048 を切り出し、886×1920へ拡大している（約1.83倍）。全長20.4秒で、場面のつなぎは0.4秒のディゾルブ、最後に0.5秒のフェードアウト。

| 出力 (秒) | 場面 | 字幕 | ビルド6との比較（`git diff 24112b8..5b3f0d6`） |
|---|---|---|---|
| 0–3.6 | ライブラリ（待機中、ミニプレイヤーなし） | Notionのデータベースをライブラリに | `LibraryRowView` で増えたのはダウンロード中にだけ出るラベルで、この場面には出ない |
| 3.2–11.2 | 動画を再生中（次の曲あり） | 添付の動画をアプリ内で再生 | 追加された待機中・エラー表示は再生が安定していれば出ない。次の曲があるので「次へ」は有効 |
| 10.8–14.2 | 項目の詳細（ミニプレイヤーは動画） | 添付ファイルとプロパティを確認 | `ItemDetailView` に変更なし。ミニプレイヤーの「次へ」は有効 |
| 13.8–17.2 | ダウンロード（保存済みの一覧） | ダウンロードしてオフライン再生 | 追加されたフッターはダウンロード中の項目にだけ付く |
| 16.8–20.4 | ライブラリ | ご自身のデータの再生には／Notionアカウントの接続が必要です | ログインが必要なことの明示（Appleの要件） |

元映像から除外した区間とその理由:

- **設定画面**: ビルド番号とソースハッシュが映る。ビルド6では「対応ファイル形式」の項目も増えている。
- **音声の再生画面、および音声をミニプレイヤーで再生中の画面すべて**: ビルド6では `.disabled(!player.canGoNext)` が加わり、キューの最後の項目を再生中は「次へ」がグレーになる（`nextIndex` はリピート設定を考慮しない）。ビルド3の映像では有効のままなので、今の見た目と一致しない。
- **プレイヤーが開く途中・黒い読み込み中の画面**: ビルド6では「再生データを読み込み中」の案内枠が出る。
- **動画が末尾まで行って先頭に戻る瞬間と、シートが閉じる途中の画面**

DRAFTをアップロードできない理由:

1. ビルド3の映像で、ビルド6の撮影証跡が無い
2. Mirroringからの拡大で解像度が足りない（Appleはネイティブ解像度での収録を推奨）
3. DB名「Playback 公開前検証 2026-10-…」が社内向けの表現で、日付も含む
4. 中身が試験用の素材（440Hzの音、カラーバー）で、実際の使い方が伝わらない
5. 音声再生を見せられない

## 公開版（candidate9、ビルド8）

元映像は、親がTestFlightで1.0.0 (8) への更新と「開く」を確認してから、iPhone 16e（iOS 27.0.1）をMirroringで録画したもの（`physical-build8-public-take1.mp4`、512×1132、可変フレームレートで約29.4fps、137.6秒）。全編Playbackだけが映り、ライブラリの2項目はオリジナルの和音AACと、元の音声を削除したNASA SVS 12118の地球タイムラプス（権利は上の「アプリ内で再生するデモ素材」）。ユーザーの放送は含まない。

切り出し範囲は実フレームの画素で測った x16 y76 w480 h1040（ウィンドウの縁とツールバーを含まない）。これを886×1920へ1.846倍に拡大している。画面の角丸（元映像で半径約64px）の外側にウィンドウの地色が見えるため、`corner_radius: 118` の黒マスクで隠した。

| 出力 (秒) | 元映像 (秒) | 場面 | 字幕 |
|---|---|---|---|
| 0–3.0 | 2.0–5.0 | ライブラリ（ミニプレイヤーなし） | Notionのデータベースが／再生ライブラリに |
| 2.6–6.2 | 25.2–28.8 | 和音を再生中の画面 | 音声をアプリ内で再生 |
| 5.8–8.8 | 34.4–37.4 | 再生中にダウンロード（読み込み中→保存済み） | ダウンロードしてオフライン再生 |
| 8.4–10.6 | 42.6–44.8 | 和音の終わり（残り0:01） | なし |
| 10.2–13.2 | 49.2–52.2 | ライブラリ。和音は再生済み、ミニプレイヤーは地球の動画 | 終わったら次の項目を自動再生 |
| 12.8–16.8 | 55.5–59.5 | 地球の動画を再生中の画面 | 動画もアプリ内で再生／（小さく）映像: NASA Goddard Space Flight Center |
| 16.4–19.4 | 118.0–121.0 | 動画の項目の詳細 | 添付ファイルとプロパティを確認 |
| 19.0–22.6 | 110.0–113.6 | ライブラリ（保存済み・再生済み） | ご自身のデータの再生には／Notionアカウントの接続が必要です |

場面のつなぎは0.4秒のディゾルブ、最後は0.5秒のフェードアウト。ポスターフレームは14.8秒（地球の動画の場面）。

判断:

- **使わなかった区間**: ミニプレイヤーや再生画面に「再生データを読み込み中」が出る区間（元映像の12.5〜17秒、46〜48秒、73〜75.5秒の動画の終わりから再開する箇所）、シートの開閉や画面遷移の途中。動画の一時停止と動画のダウンロード（89.5〜103秒）は、音声のダウンロードと内容が重なるため入れなかった。親が最後に戻る操作をしたが詳細画面のままなので、締めには同じ録画のライブラリ（110〜113.6秒）を詳細の後に置いた。
- **字幕の位置**: 音声の再生画面は操作ボタンが動画より下にあるため、字幕を画面下端の空き（y=0.915）に置いた。動画の再生画面はy=0.80。
- **NASAのクレジット**: 動画の場面だけに、小さく半透明の文字で入れた。タイトルや字幕にはNASAの名前を出さず、推薦を思わせる表現はしない。
- **解像度の限界**: Mirroringの録画は480×1040しかなく、886×1920へ拡大すると文字の輪郭がやや柔らかくなる。等倍で見ても読めるが、Appleが推奨するネイティブ解像度での収録には及ばない。今回の指示により、過去のビルドの素材との差し替えはしない。
- **音声**: 元映像の音声トラックは使わず、生成した無音（AAC 256 kbps）を入れる。
- **最後の字幕（final-v2で変更）**: v1の「ご利用にはNotionアカウントの／接続が必要です」では、アプリ内蔵のアカウント不要デモまでログインが必要と読めてしまう。そのため、自分のデータを再生する場合に限ることが伝わる文言に変えた。44 pxの2行で収まる。変えたのはこの字幕だけで、v1とのフレームごとのPSNRは最後の場面より前で53.75 dB以上。

## 新規撮影リスト（TestFlight 1.0.0 (6)、記録）

撮影の準備:

- TestFlightからインストールした1.0.0 (6) を使う（開発ビルドや自動操作を仕込んだビルドは不可）。設定画面での表示確認は撮影とは別に行い、そのカットは使わない。
- 日本語UI、集中モードをオンにする。通知・他のアプリ・Notionの画面・OAuthの画面は映さない。
- 収録は、できればQuickTimeのUSB収録で 1170×2532 以上のネイティブ解像度にする。Mirroringを使う場合はウィンドウを最大にする。
- 使うDBは日付や「検証」などを含まない中立的な名前にする。項目は権利を持つ音声・動画を2〜4件（自分の声のメモ、自作の素材など）。NHKなど第三者の放送は使わない。
- 各カットは操作が終わって画面が落ち着いた状態を6〜10秒撮る。読み込み中やエラーの画面は撮らない。

| # | 撮るもの | 長さ | 注意 |
|---|---|---|---|
| S1 | ライブラリの一覧（ミニプレイヤーなし） | 8秒 | フィルターのチップと複数の項目が見えること |
| S2 | 後ろに別の項目がある音声を再生中の画面 | 8秒 | 開いてから最初の約2秒（読み込み）は使わない。「次へ」が有効であること |
| S3 | 動画を再生中の画面 | 10秒 | 末尾まで行って先頭に戻る瞬間をまたがない |
| S4 | 項目の詳細（ミニプレイヤーあり） | 5秒 | メディアファイルとプロパティが見えること |
| S5 | ダウンロード画面の保存済み一覧 | 5秒 | ダウンロード中の項目がないこと |
| S6 | ミニプレイヤーが出ているライブラリ | 5秒 | 最後の場面。ログインの明示を字幕で入れる |

撮影後は、EDLの `footage` をビルド6・`verified_on_device: true` に直して `render` を実行し、レポートの全チェックが通ることと、人の目で全フレームを確認したことの両方を満たしてから親に渡す。

## アプリ内で再生するデモ素材（candidate8、2026-10-25）

撮影用DBに入れる項目のうち、試験用の素材（440Hzの音、カラーバー）を置き換えるためのもの。素材そのもの・元の映像・QA結果・権利の確認記録（`RIGHTS.md`）・`manifest.json`（MIME、サイズ、SHA-256）は、Git外の `~/.config/playback/release/candidate8/app-preview/media/` に置く。

| 素材 | 中身 | 権利 |
|---|---|---|
| 地球のタイムラプス（25秒、1280x720、H.264、音声なし） | NASA SVS 12118 "Earth Time-lapse" の公式HLS 1280x720のうち5〜30秒。元の音声トラックは削除した | NASAのガイドラインに基づき条件付きで使用可。NASAが推薦しているように見せない。クレジット「NASA's Goddard Space Flight Center」はNotion項目のプロパティか本文に入れ、タイトルには入れない。ロゴや人物は映っていない |
| 和音のスケッチ（30秒、AAC 256k ステレオ） | FFmpeg `aevalsrc` で合成したオリジナルの8小節 | こちら側のオリジナル。第三者の素材は使っていない |

Notionの無料ワークスペースは1ファイル5 MiBまでなので、映像（約12.8 MiB）を入れるDBは有料ワークスペースに置く。

## アップロード時の注意（担当は親）

- App Store Connectでは、iPhoneの大画面（6.9インチ相当）に886×1920を1本入れる。中画面は縮小された版が自動で使われる。
- ポスターフレームは書き出したときの `poster_seconds` に合わせる（既定の5秒）。
- アップロードと審査への提出はこの制作作業の範囲外。
